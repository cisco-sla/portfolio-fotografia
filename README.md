# Página Web "Portfolio Personal de Fotografía" con React para la Materia Programación Web II (Upateco - 2026)

Página web tipo portfolio o blog de fotografía, con 3 páginas gestionadas por React: Inicio - Portfolio - Contacto

Inicio: Galeria de imágenes con llamada a la API de Lorem Picsum.
Portfolio: Galería de imágens propias
Contacto: Formulario de Contacto y Mapa
